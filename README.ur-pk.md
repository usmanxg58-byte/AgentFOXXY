## AgentFOXXY کیا ہے؟

AgentFOXXY ایک خود مختار AI ایجنٹ ہے جو واقعی کام مکمل کرتا ہے۔ یہ کوڈ لکھتا اور چلاتا ہے، براؤزر چلاتا ہے، میڈیا بناتا ہے، ویب پر تلاش کرتا ہے، اہم باتیں یاد رکھتا ہے، اور متوازی کام کے لیے اپنے مددگار ایجنٹ خود بناتا ہے — یہ سب ایک ہی کمانڈ سے۔

یہ **ماڈل سے آزاد** ہے: OpenAI، OpenRouter، کوئی مقامی اینڈ پوائنٹ، یا کوئی بھی OpenAI سے مطابقت رکھنے والا گیٹ وے استعمال کریں۔ ایک کمانڈ سے ماڈل بدلیں — نہ کوڈ تبدیل کرنا پڑے گا، نہ کسی پابندی میں بندھیں گے۔

اور یہ **خود کو بہتر بناتا ہے**: اپنے تجربے سے نئی مہارتیں (skills) بناتا ہے، استعمال کے ساتھ ان کو نکھارتا ہے، اپنی پرانی گفتگو تلاش کر لیتا ہے، اور ہر سیشن میں آپ کے بارے میں گہری سمجھ پیدا کرتا جاتا ہے۔

## 🚀 ڈاؤن لوڈ اور انسٹالیشن

AgentFOXXY حاصل کرنے کے تین طریقے ہیں — جو آپ کو موزوں لگے وہ چن لیں۔

### 1. 🖥️ ڈیسک ٹاپ ایپ (سب سے آسان — ونڈوز)

انسٹالر ڈاؤن لوڈ کریں، ڈبل کلک کریں، بس۔ کسی ٹرمینل کی ضرورت نہیں۔

**➡️ [تازہ ترین ریلیز ڈاؤن لوڈ کریں](https://github.com/usmanxg58-byte/AgentFOXXY/releases/latest)**

| فائل | کس کے لیے |
|---|---|
| `AgentFOXXY-*-win-x64.exe` | عام انسٹالیشن (تجویز کردہ) |
| `AgentFOXXY-*-win-x64.msi` | کمپنی / خاموش (silent) تنصیب |

> پہلی بار چلانے پر ونڈوز "unknown publisher" کا پیغام دکھا سکتا ہے — **More info → Run anyway** پر کلک کریں۔ ایپ محفوظ ہے، صرف پیڈ سائننگ سرٹیفکیٹ موجود نہیں۔

### 2. ⌨️ کمانڈ لائن انسٹالیشن (لینکس · میک او ایس · WSL2 · Termux · ونڈوز)

**لینکس / میک او ایس / WSL2 / Termux:**

```bash
curl -fsSL https://raw.githubusercontent.com/usmanxg58-byte/AgentFOXXY/main/scripts/install.sh | bash
```

**ونڈوز (مقامی، پاور شیل):**

```powershell
iex (irm https://raw.githubusercontent.com/usmanxg58-byte/AgentFOXXY/main/scripts/install.ps1)
```

انسٹالر سب کچھ خود سنبھال لیتا ہے — `uv`، Python 3.11، Node.js، ripgrep، ffmpeg، اور ونڈوز پر ایک پورٹ ایبل گٹ بیش (ایڈمن اجازت کی ضرورت نہیں، اور سسٹم کے کسی بھی گٹ سے مکمل الگ)۔ مقامی ونڈوز مکمل طور پر سپورٹڈ ہے: CLI، گیٹ وے، TUI اور تمام ٹولز WSL کے بغیر چلتے ہیں۔

پھر اپنا شیل دوبارہ لوڈ کریں اور بات چیت شروع کریں:

```bash
source ~/.bashrc    # یا: source ~/.zshrc
agentfoxxy
```

### 3. 🛠️ سورس سے (ڈیویلپرز کے لیے)

```bash
git clone https://github.com/usmanxg58-byte/AgentFOXXY.git
cd AgentFOXXY
uv pip install -e ".[all]"
agentfoxxy
```

## 🎯 آغاز کیسے کریں

```bash
agentfoxxy              # انٹرایکٹو CLI — گفتگو شروع کریں
agentfoxxy model        # اپنا LLM پرووائیڈر اور ماڈل چنیں
agentfoxxy tools        # کون سے ٹولز فعال ہوں، یہ طے کریں
agentfoxxy gateway      # میسجنگ گیٹ وے چلائیں (ٹیلی گرام، ڈسکارڈ، …)
agentfoxxy setup        # مکمل سیٹ اپ وزرڈ — سب کچھ ایک ساتھ ترتیب دیں
agentfoxxy update       # تازہ ترین ورژن پر اپ ڈیٹ کریں
agentfoxxy doctor       # مسائل کی تشخیص کریں
```

AgentFOXXY کو اپنی پسند کے کسی بھی پرووائیڈر پر لگائیں:

```bash
agentfoxxy model        # انٹرایکٹو طریقے سے پرووائیڈر + ماڈل چنیں
agentfoxxy -z "FastAPI میں ٹیسٹس کے ساتھ ایک REST API بنا دو"   # ایک بار کا کام
```

## 💬 CLI اور میسجنگ

AgentFOXXY کے دو دروازے ہیں: ٹرمینل UI (`agentfoxxy`)، یا وہ گیٹ وے جس سے آپ ٹیلی گرام، ڈسکارڈ، سلیک، واٹس ایپ یا سگنل پر بات کرتے ہیں۔ زیادہ تر سلیش کمانڈز دونوں جگہ کام کرتی ہیں۔

| کام | CLI | میسجنگ |
|---|---|---|
| بات چیت شروع کریں | `agentfoxxy` | `agentfoxxy gateway setup` + `gateway start`، پھر بوٹ کو میسج کریں |
| نئی گفتگو | `/new` یا `/reset` | `/new` یا `/reset` |
| ماڈل بدلیں | `/model [provider:model]` | `/model [provider:model]` |
| پرسنلٹی سیٹ کریں | `/personality [name]` | `/personality [name]` |
| دوبارہ کوشش / واپس | `/retry`، `/undo` | `/retry`، `/undo` |
| کانٹیکسٹ اور استعمال | `/compress`، `/usage` | `/compress`، `/usage` |
| مہارتیں | `/skills` یا `/<skill-name>` | `/<skill-name>` |
| روکیں | `Ctrl+C` یا نیا میسج | `/stop` یا نیا میسج |

## 🤝 تعاون

پہلے انسٹالر استعمال کریں، پھر جو گٹ چیک آؤٹ وہ
`$AGENTFOXXY_HOME/agentfoxxy-agent` (عام طور پر `~/.agentfoxxy/agentfoxxy-agent`) میں بناتا ہے، اسی میں کام کریں:

```bash
cd "${AGENTFOXXY_HOME:-$HOME/.agentfoxxy}/agentfoxxy-agent"
uv pip install -e ".[all,dev]"
scripts/run_tests.sh
```
