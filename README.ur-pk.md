## اسے کام کرتے دیکھیں

**اسے کام دیں اور چلے جائیں:**

```bash
agentfoxxy -z "sales.csv پڑھیں، 5 بدترین مہینے تلاش کریں، چارٹ بنائیں، report.png کے طور پر محفوظ کریں"
```

یہ فائل کھولتا ہے، نمبر نکالتا ہے، پلاٹنگ کوڈ لکھتا ہے، چلاتا ہے، بنائی گئی تصویر دیکھتا ہے، اور اگر چارٹ غلط نکلا تو ٹھیک کرتا ہے۔

**اسے براؤزر چلانے دیں:**

```bash
agentfoxxy
> ایڈمن پینل میں لاگ ان کریں، پچھلے مہینے کے آرڈرز ایکسپورٹ کریں، اور مجھے ٹوٹل ای میل کریں
```

HTML سکریپنگ نہیں — ایک حقیقی براؤزر جسے یہ دیکھ سکتا ہے، کلک کر سکتا ہے، اور ٹائپ کر سکتا ہے۔

**اپنے فون سے پیغام بھیجیں:**

```bash
agentfoxxy gateway start
```

اب Telegram، Discord، Slack، WhatsApp، یا Signal پر پیغام بھیجیں۔ وہی ایجنٹ، وہی یادداشت، وہی بات چیت جو آپ نے ٹرمینل میں کھلی چھوڑی تھی۔

**مستقل حکم دیں:**

```
> ہر ہفتے کے دن صبح 8 بجے، میری repos چیک کریں ناکام بلڈز کے لیے اور مجھے خلاصہ بھیجیں
```

کوئی cron syntax نہیں۔ یہ خود شیڈول بناتا ہے۔

بہت سے ٹولز اپنے آپ کو ایجنٹ کہتے ہیں۔ یہاں حقیقت میں مختلف کیا ہے، اور یہ کیسے کام کرتا ہے۔

### 🧠 یہ بہتر ہوتا ہے — اور آپ پڑھ سکتے ہیں کیوں

جب AgentFOXXY کچھ پیچیدہ حل کرتا ہے، تو یہ طریقہ **سکل** کے طور پر محفوظ کرتا ہے: آپ کے سکلز فولڈر میں ایک سادہ markdown فائل۔ آپ اسے کھول سکتے ہیں، ایڈٹ کر سکتے ہیں، ڈیلیٹ کر سکتے ہیں، یا کسی ساتھی کو بھیج سکتے ہیں۔ کچھ بھی بلیک باکس میں بند نہیں۔

یہ اپنے قابل تلاش نوٹس بھی رکھتا ہے اور ہر پچھلی بات چیت کو دوبارہ دیکھ سکتا ہے، تو آپ ہر صبح اپنی سیٹنگ دوبارہ بتانا چھوڑ دیتے ہیں۔

### 🔌 یہ ایک AI کمپنی سے بندھا نہیں

35+ فراہم کنندگان باکس سے باہر کام کرتے ہیں — OpenAI، Anthropic، Gemini، DeepSeek، Qwen، xAI، Bedrock، Azure، OpenRouter، Ollama، اور کوئی بھی OpenAI-مطابق endpoint جس کی طرف آپ اشارہ کریں۔

## 🚀 انسٹال کریں

تین راستے اندر۔ ایک چنیں۔

### 1. ڈیسک ٹاپ ایپ — سب سے آسان (Windows · macOS)

ڈاؤن لوڈ کریں، ڈبل کلک کریں، ہو گیا۔ کوئی ٹرمینل نہیں۔

**➡️ [تازہ ترین ریلیز حاصل کریں](https://github.com/usmanxg58-byte/AgentFOXXY/releases/latest)**

| فائل | اس کے لیے استعمال کریں |
|---|---|
| **Windows** | |
| `AgentFOXXY-*-win-x64.exe` | عام انسٹال — یہاں سے شروع کریں |
| `AgentFOXXY-*-win-x64.msi` | کمپنی / خاموش تعیناتی |
| **macOS** | |
| `AgentFOXXY-*-mac-arm64.dmg` | Apple Silicon (M1/M2/M3) |
| `AgentFOXXY-*-mac-x64.dmg` | Intel Mac |

> **Windows:** پہلی بار "نامعلوم پبلشر" کی وارننگ آ سکتی ہے — کلک کریں **مزید معلومات → پھر بھی چلائیں**۔ اس وارننگ کا مطلب ہے انسٹالر ابھی پیسے دے کر سائن نہیں ہوا، نہ کہ اس میں کچھ غلط ہے۔
> 
> **macOS:** ایپ پر رائٹ کلک کریں → اوپن (صرف پہلی بار) Gatekeeper کو نظر انداز کرنے کے لیے، یا Terminal میں `xattr -cr /Applications/AgentFOXXY.app` چلائیں۔

### 2. ایک کمانڈ (Linux · macOS · WSL2 · Termux)

```bash
curl -fsSL https://raw.githubusercontent.com/usmanxg58-byte/AgentFOXXY/main/scripts/install.sh | bash
```

**Windows PowerShell:**

```powershell
iex (irm https://raw.githubusercontent.com/usmanxg58-byte/AgentFOXXY/main/scripts/install.ps1)
```

انسٹالر اپنا `uv`، Python 3.11، Node.js، ripgrep اور ffmpeg لاتا ہے — Windows پر portable Git Bash بھی۔ کوئی ایڈمن حقوق نہیں، اور آپ کے سسٹم پر جو پہلے سے ہے اسے اکیلا چھوڑ دیتا ہے۔

پھر:

```bash
source ~/.bashrc    # یا: source ~/.zshrc
agentfoxxy
```

### 3. سورس سے (ڈویلپرز)

```bash
git clone https://github.com/usmanxg58-byte/AgentFOXXY.git
cd AgentFOXXY
uv pip install -e ".[all]"
agentfoxxy
```

```bash
agentfoxxy setup        # ایک wizard: ماڈل، کیز، ٹولز — سب کچھ
agentfoxxy              # بات شروع کریں
```

اس کے بعد کارآمد:

```bash
agentfoxxy model        # فراہم کنندہ یا ماڈل تبدیل کریں
agentfoxxy tools        # ٹولز آن اور آف کریں
agentfoxxy gateway      # Telegram / Discord / Slack / WhatsApp / Signal جوڑیں
agentfoxxy -z "..."     # ایک کام چلائیں اور باہر نکلیں — کوئی چیٹ نہیں
agentfoxxy update       # جگہ پر اپ ڈیٹ کریں
agentfoxxy doctor       # کچھ ٹوٹا ہے؟ یہاں سے شروع کریں
```

## 🔍 جاننے کے لائق

- **یہ خطرناک کمانڈز چلانے سے پہلے پوچھتا ہے۔** ایک بار منظور کریں، یا اپنی اجازت کی فہرست میں پیٹرن شامل کریں تاکہ یہ پوچھنا بند کر دے۔ `agentfoxxy approvals` آپ کی منظوریوں کی بنیاد پر اجازت کی فہرست کی تجاویز بھی دے گا۔
- **آپ کی کیز آپ کی ہیں۔** آپ فراہم کنندہ چنتے ہیں اور ایجنٹ اس سے براہ راست بات کرتا ہے۔ مشترکہ gateways اور subscription routing موجود ہیں اگر آپ ایک بل چاہتے ہیں دس API کیز کی بجائے — لیکن وہ آپشنل ہیں، کبھی ڈیفالٹ نہیں۔
- **اپنا ماڈل لائیں۔** اسے اپنی مشین پر Ollama کی طرف اشارہ کریں اور کچھ بھی عمارت سے باہر نہیں جاتا۔
- **ضروریات:** Linux، macOS، یا Windows پر Python 3.11+۔ انسٹالر باقی سنبھالتا ہے۔
